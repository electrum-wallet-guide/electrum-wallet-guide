Desktop app

Desktop Electrum is available for supported Windows, macOS and Linux environments. Desktop use is often preferred when users want access to the wallet's broader feature set.

Android app

The Electrum project links to its Android distribution through Google Play, F-Droid and downloadable Android packages.

Before installing

Confirm the publisher, source and destination URL. A wallet app should never require you to provide a seed phrase to a website or a person offering private support.

Official resources

Use project-owned resources when downloading software or following technical instructions.

Common questions

Is this the official Electrum website?

No. This is an independent educational resource. Use electrum.org for the official project website.

Can I enter my seed phrase here?

No. Never enter or send a seed phrase, private key, wallet file or wallet password to this website.

Where should I download Electrum?

Use the official Electrum project website and the distribution channels it links to.

Does this site provide private wallet support?

No. It provides general educational information and routes users to public official resources.

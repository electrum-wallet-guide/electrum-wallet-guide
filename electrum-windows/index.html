Common questions

Is this the official Electrum website?

No. This is an independent educational resource. Use electrum.org for the official project website.

Can I enter my seed phrase here?

No. Never enter or send a seed phrase, private key, wallet file or wallet password to this website.

Where should I download Electrum?

Use the official Electrum project website and the distribution channels it links to.

Does this site provide private wallet support?

No. It provides general educational information and routes users to public official resources.
